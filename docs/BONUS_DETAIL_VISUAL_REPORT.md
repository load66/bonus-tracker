## Release acceptance

- Chase synthetic offer `CHA-P-01` renders “Direct deposits totaling $10,000 · due Jan 13, 2027” and “$0 of $10,000 · 0 recorded”, with an accessible checkbox and zero-progress bar.
- A requirement without a checklist task does not present an empty Requirements section.
- Timer titles are limited to a single visual line, with a separate muted date line and countdown pill. Full original timer text appears on expansion.
- Waivers display ANY/ALL with a CSS two-line clamp; “View full terms” displays saved text without rewriting it. Unconfirmed early closure charges remain amber.
- Missing safe-close/eligibility rules show “Needs review” and open the existing entry editor. Activity is reachable via account actions, not inside the detail.
- Only synthetic UI fixtures are used; no persisted bonus/financial record, provider state or canonical financial rule is changed.

The source PDF uses illustrative offer information. Values in screenshots are synthetic test fixtures and do not establish actual bank eligibility or safe closure.
