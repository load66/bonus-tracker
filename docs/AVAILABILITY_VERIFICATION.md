# Official availability verification

The availability service checks the fixed public discovery catalog hourly and publishes exact-offer records. It checks approved institution domains and public promotion documents; publisher links only discover official candidates. Unsupported institution identities, unavailable pages, missing scope and conflicting clauses remain unconfirmed. No bank footprint, nationwide ATM network or absent restriction proves promotional eligibility.

Evidence receipts include title/URL fingerprint, source URL, document SHA-256, original scope quotation, check timestamp and a 24-hour expiry. Promotion reward/product and explicit headline deadlines must match the official document. Current official deadlines can exclude ended promotions. Bank pages can change between checks; this is not guaranteed real-time data.

The mobile tab independently loads live scope results and a published offline snapshot. It validates identity, source hosts, hash format, timestamps, scope rules and expiry. Expired evidence loses verified status. Each card exposes the source and quotations. Source-feed timestamps are separate from official scope-check timestamps.

Read-only tracker ranking uses canonical dates and personal/business identity. Up to eight public catalog URLs from ready/next tracked matches are submitted after sign-in to prioritize official work. No account IDs, balances, opening/closure dates, notes, credentials or full records are included in the priority body. Public lookup does not require login; priority submission uses the existing owner authorization.

Geographic scope is distinct from personal eligibility. Membership, county, ZIP-code and invitation conditions require review; the app never labels all users eligible merely because their state appears. New institutions require verified domain onboarding. Regional source reports remain labeled reports when no official scope exists.

Checks use bounded batches, concurrency, response sizes, request timeouts and redirect host validation. Records are not updated by new public terms; imports still follow the strict generation standard and explicit review. No persistent tracker key or backup format is changed.
